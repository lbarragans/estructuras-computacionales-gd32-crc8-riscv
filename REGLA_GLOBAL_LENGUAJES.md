# Regla global de lenguajes

La barra **Languages** de GitHub debe representar los lenguajes realmente usados
en las implementaciones educativas.

- C cuenta cuando implementa parte real de la solucion.
- Assembly cuenta cuando implementa parte real de la solucion.
- FreeRTOS es tecnologia, no lenguaje.
- PowerShell, CMake, JSON, VS Code y Markdown son auxiliares.
- No se oculta C ni Assembly para fabricar porcentajes.
