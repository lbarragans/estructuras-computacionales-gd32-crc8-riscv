# 08 - Inyeccion de errores y comparacion C/Assembly

## Lenguajes

C + Assembly (usa la funcion Assembly existente).

## Prueba

Se cambia cada bit individual del mensaje y se recalcula el CRC.

El objetivo no es demostrar matematicamente todas las propiedades del codigo,
sino construir evidencia experimental reproducible.
