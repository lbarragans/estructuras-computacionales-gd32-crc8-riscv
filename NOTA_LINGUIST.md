# GitHub Linguist en este repositorio

Este ejercicio contiene implementaciones reales en C y Assembly RISC-V.

GitHub puede mostrar ambos lenguajes:

```text
C          xx.x %
Assembly   yy.y %
```

Los porcentajes exactos dependen del codigo.

PowerShell, CMake, JSON, configuracion de VS Code y Markdown no deben alterar la
barra de lenguajes.
